# Contributing to Freate

Thank you for considering contributing to Freate!

## How to Contribute

### Reporting Bugs

1. Check [issues](https://github.com/freatevietnam/freate/issues) to see if it's already reported
2. If not, open a new issue with:
   - A clear title and description
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots (if applicable)

### Suggesting Features

Open an issue with the `enhancement` label and describe:
- The problem you're trying to solve
- How you envision the solution
- Any alternatives considered

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feat/amazing-feature`)
3. Commit your changes (`git commit -m 'feat: add amazing feature'`)
4. Push to your branch (`git push origin feat/amazing-feature`)
5. Open a Pull Request

## Code Standards

- **HTML**: Semantic HTML5, valid markup
- **CSS**: Pure CSS, no preprocessors
- **JavaScript**: ES6+, no runtime dependencies
- **Responsive**: Mobile, tablet, desktop compatible

## Commit Style

We follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` — new feature
- `fix:` — bug fix
- `docs:` — documentation
- `style:` — formatting, styling
- `refactor:` — code restructuring
- `perf:` — performance improvement
- `chore:` — maintenance
