Freate Diary

Sổ tay nhật ký điện tử mã hóa đầu cuối với bảo mật cấp quân sự. Tích hợp theo dõi cảm xúc, lưu trữ tập tin và xem trực tiếp theo thời gian thực.

  • Mã hóa phần cứng AES-256-GCM
  • Cập nhật trực tiếp qua SSE (Server-Sent Events)
  • Hỗ trợ Markdown, KaTeX toán học & tô sáng code

Freate Drop Python & Rust

Nền tảng chia sẻ Markdown ẩn danh tức thì với ID 32 ký tự. Hỗ trợ 2 bản build hoàn chỉnh bằng Python và Rust cho hiệu năng cực cao.

  • Quản lý ẩn danh qua Cookie mã hóa Fernet / AES
  • Khóa bảo vệ mật lưu, URL ngắn, chế độ In & Fullview
  • Phím tắt thông minh: F1 (Help), F (Full), P (Print), Ctrl+Enter

FreateOJ

Hệ thống chấm bài trực tuyến (Online Judge) chính thức của Freate cho các cuộc thi lập trình thuật toán với hạ tầng Docker cách ly tuyệt đối.

  • Hỗ trợ hơn 56+ ngôn ngữ lập trình
  • Định dạng kỳ thi linh hoạt (IOI, ICPC, Custom)
  • Cập nhật tiến độ bài nộp qua Socket.IO thời gian thực

FreateOJ Wiki Builder

Ứng dụng Desktop GUI đơn tệp (Single-file) đóng gói tài liệu Wiki ra HTML tĩnh. Chạy mượt trên Windows, macOS và Linux với SQLite.

  • Giao diện Desktop GUI egui 6 tab trực quan
  • Chuyển trang mượt mà không load với htmx
  • Tự động chuyển đổi logo SVG sang favicon ICO & SEO từng trang

Tại sao chọn Freate?

Cam kết mã nguồn mở minh bạch và kiến trúc công nghệ tiên tiến.

100% Mã nguồn mở

Toàn bộ mã nguồn minh bạch trên GitHub, sẵn sàng cho cộng đồng kiểm tra và đóng góp.

Bảo mật quân sự

Mã hóa AES-256-GCM, Argon2id, cookie HttpOnly Fernet mã hóa bảo vệ tối đa dữ liệu.

Tối ưu hiệu năng
